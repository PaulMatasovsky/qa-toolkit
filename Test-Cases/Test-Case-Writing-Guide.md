# Test Case Writing Guide

*AI-generated reference; use alongside the blank [test case template](Test-Case-Template.md).*

A good test case is clear, repeatable, and focused on one behavior.

- Identify the feature or requirement being checked.
- Define the conditions and safe test data needed.
- Write steps that another tester can follow.
- State the expected result for each important action.
- Keep execution results separate from expected behavior.
- Record observed results, evidence, and linked defects after running the test.
- Mark tests **NOT RUN** until executed; don't assume a generated scenario is verified.
- Update cases when requirements change.
