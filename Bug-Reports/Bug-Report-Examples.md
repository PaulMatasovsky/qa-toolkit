# Bug Report Examples

*AI-generated, fictional examples for learning. No application was tested and no defect was observed.*

## Too Vague

> **Title:** Login broken
>
> **Description:** Login doesn't work.

This doesn't tell another person where the issue occurred, what steps caused it, or what was expected.

## More Useful

**Title:** Login button stops responding after three failed attempts

- **Application:** Hypothetical web application
- **Environment:** Desktop browser (version would be recorded in a real report)
- **Severity:** High (illustrative)
- **Priority:** P1 (illustrative)
- **Precondition:** A test account is available

**Steps to reproduce (fictional):**

1. Open the login page.
2. Submit an incorrect password three times.
3. Enter valid test credentials.
4. Select **Login**.

**Expected result:** The application follows its sign-in rules and either permits access or provides a clear response.

**Actual result (fictional):** The Login button does not respond until the page is refreshed.

**Evidence:** None. A real report would include the browser details and relevant screenshots, recordings, or console messages.

The second example gives another person something concrete to investigate. It is still only a writing example, not a verified defect.
