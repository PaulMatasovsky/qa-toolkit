# Example: Well-Structured Bug Report

**Fictional, AI-generated example.** No application was tested and no defect was observed.

- **Title:** Login button stops responding after three failed attempts
- **Severity:** High
- **Priority:** P1 (illustrative)
- **Environment:** Example application in a desktop browser
- **Frequency:** Hypothetically reproducible every time

## Summary

In this fictional scenario, after three consecutive failed login attempts, the Login button stops responding until the page is refreshed.

## Preconditions

The user is on the example application's login page and has a test account.

## Steps to Reproduce

1. Open the login page.
2. Enter an incorrect password and submit.
3. Repeat the failed attempt twice.
4. Enter valid test credentials.
5. Select **Login**.

## Expected Result

The application handles unsuccessful attempts as specified and allows valid sign-in when permitted.

## Actual Result (Fictional)

The Login button no longer responds.

## Evidence

A real report would include a screen recording, console output, and the environment details. **No evidence was collected for this fictional example.**

## Additional Note

In this example, refreshing the page would restore the button's response.
