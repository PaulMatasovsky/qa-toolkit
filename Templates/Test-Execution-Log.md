**Result meanings**

- **Pass:** The actual result matched the expected result.
- **Fail:** The actual result did not match. Write a [bug report](Bug-Report.md) and put its ID in the Bug ID column.
- **Blocked:** The check could not be run. Say why in the "What actually happened" column.
- **N/A:** The check does not apply to this project.

**Follow-up items:**

When the cycle is finished, total the results in the [summary report](Test-Summary-Report.md).
