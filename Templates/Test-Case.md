## Writing Tips

- Test one behavior per case.
- Write steps another person could follow without asking you questions.
- State the expected result before you test, so the result is not shaped by what you see.
- For input fields, check values at and around each limit. See [Test Design Techniques](../Reference/Testing-Types.md#test-design-techniques).
